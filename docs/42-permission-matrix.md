## 1. 결정 사항

| # | 안건 | 결정 | 이유 |
|---|---|---|---|
| P-1 | 권한 검사 위치 | **Service에서 매번** (화면 숨김은 보조) — 기존 결정 (02 §5, 01 §3-3) | 주소 직접 입력·요청 조작으로 화면 숨김을 우회할 수 있다 |
| P-2 | 판정 순서 | **§3의 5단계 순서**를 모든 기능이 같은 순서로 적용 | 같은 상황에서 기능마다 다른 응답 코드가 나오지 않게 한다 |
| P-3 | 응답 코드 | **§4 표 하나로 통일** (401 / 403 / 404 / 400 / 409) | 화면·API·테스트가 같은 기준을 쓴다 |
| P-4 | 남의 것·볼 수 없는 것 | **404** — 기존 결정 (06 V-5, 05 §10-5) | 존재 여부를 드러내지 않는다 |
| P-5 | 계정 상태 때문에 막힘 | **403** + 이유 코드 (`EMAIL_NOT_VERIFIED`, `ACCOUNT_WITHDRAWN`). 정지는 로그인 단계에서 막힌다 (P-7) | 대상의 존재가 아니라 "내 계정"의 문제라서 숨길 것이 없다. 사용자가 해결 방법(인증 메일, 정지 기간)을 알아야 한다 |
| P-6 | 인증 전 회원의 좋아요·신고 | **막는다** (07은 글쓰기·댓글·사진만 명시 → 좋아요·신고 추가) | 가입만 하고 인증하지 않은 계정으로 좋아요를 부풀리거나 신고를 남용하는 것을 막는다 |
| P-7 | 정지 회원 | **로그인 차단.** 정지하는 순간 모든 기기에서 로그아웃(Redis 세션 삭제)되고, 로그인하면 "정지된 계정이에요 (~11월 1일, 사유)"만 보여준다. 그 사람은 사이트에서 **비회원과 같다.** 이미 쓴 글·댓글은 그대로 보인다 | 정지 중에는 어떤 행동도 남기지 못하게 단순하게 막는다. 콘텐츠를 가리는 것은 정지와 별개로 관리자 숨김이 맡는다 ([43 문서](./43-report-hide.md)) |
| P-8 | 블로그 주인이 내 글에 달린 남의 댓글 삭제 | **불가** — 기존 결정 (01 C-CMT-1 "본인만 수정·삭제"), [21 댓글](./21-comment.md) CM-10과 같음. 글 주인은 댓글에 대해 **일반 회원과 같다** | 악성 댓글은 신고 → 관리자 숨김(43)으로 처리한다. 글 주인 삭제는 개인 확장 (공통 변경은 화요일 회의에 제안만) |
| P-9 | 자기 글 좋아요 | **불가** (400 `CANNOT_LIKE_OWN_POST`), 버튼 대신 좋아요 수만 표시 — [30 좋아요](./30-like.md) K-1과 같음 | 인기 글·트렌딩 점수를 스스로 올리는 것을 막는다. 응답 코드는 §4 원칙(403은 계정 상태만)에 따라 400 — 30은 403으로 적혀 있어 맞춤 요청 |
| P-10 | 관리자 기능 주소(`/admin/**`) 접근 | **비회원 401, 로그인한 일반 회원 404** (회의 P3) | `/admin/**` 전체를 로그인 필요로 묶으므로 비회원은 없는 주소(`/admin/xyz`)에서도 똑같이 401이라 관리자 화면이 있다는 사실이 드러나지 않는다. 로그인한 일반 회원에게는 404로 숨긴다. Spring Security 기본 설정으로 구현된다 |
| P-11 | 관리자의 글·댓글 처리 | **숨김만, 수정·삭제 불가** — 기존 결정 (05 §8). 남의 비공개 글도 볼 수 없다 (06 §2) | 작성자의 콘텐츠를 운영자가 바꾸지 않는다 |
| P-12 | 탈퇴 유예 회원 | 로그인하면 **복구 화면만** (복구하기 / 로그아웃). 그 외 모든 요청은 복구 화면으로 이동(SSR) 또는 403 `ACCOUNT_WITHDRAWN`(REST) — 13 §3-2 기반 | 복구 전에는 아무 행동도 남기지 않는다 |

## 2. 행위자

| 행위자 | 판별 | 비고 |
|---|---|---|
| **비회원** | 로그인하지 않음 | |
| **인증 전 회원** | 로그인함, `auth_identity.email_verified_at IS NULL` (이메일 가입만) | 소셜 가입은 가입 시각으로 인증됨 (07) |
| **회원** | 로그인함, 인증 완료, `status = ACTIVE` | 아래 "작성자"가 아닌 다른 회원 |
| **작성자** | 회원 중 대상의 `author_id = 현재 사용자` | 글이면 글쓴이 = 블로그 주인. 댓글이면 댓글 쓴 사람. 글 주인은 남의 댓글에 대해 일반 회원과 같다 (P-8) |
| **관리자** | `role = ADMIN` | 관리자도 자기 글에서는 작성자다 |
| **정지 회원** | `status = SUSPENDED` | P-7: 로그인할 수 없으므로 아래 표에서는 **비회원과 같다** (표에서 칸을 따로 두지 않음) |
| **탈퇴 유예 회원** | `status = WITHDRAWN`, `deleted_at IS NULL` | P-12 |

> 표에서 **회원**은 "작성자가 아닌 다른 회원"을 뜻한다. 한 사람이 여러 행위자에 해당하면 §3 판정 순서에 따라 먼저 걸리는 쪽이 적용된다 (예: 인증 전인 작성자가 발행 → 인증 전 규칙으로 403).

## 3. 판정 순서

모든 요청은 아래 순서로 검사하고, **처음 걸린 단계의 응답**을 준다.

```
① 로그인 필요?          로그인이 필요한 행동인데 비회원 → 401 (SSR은 로그인 화면으로, 돌아올 주소 포함)
② 계정 상태            탈퇴 유예 → 복구 화면 / 403 ACCOUNT_WITHDRAWN
                        인증 전 + 쓰기 행동 → 403 EMAIL_NOT_VERIFIED
                        (정지 회원은 로그인 자체가 안 되므로 여기까지 오지 않는다. 정지 시점에 세션도 삭제)
③ 대상을 볼 수 있나?    없음·삭제됨(휴지통)·숨김(남이 볼 때)·작성자 탈퇴 유예·공개 범위상 볼 수 없음 → 404
                        (PostAccessPolicy.canRead — 06 §7 R-1)
④ 이 행동을 할 권한?    소유자만 가능한 행동인데 소유자가 아님 → 404
                        관리자 전용인데 관리자가 아님 → 404 (P-10, 비회원은 ①에서 401)
⑤ 업무 규칙            자기 글 좋아요·자기 것 신고 등 → 400 / 상태 충돌 → 409
```

- ②가 ③보다 먼저인 이유: 인증 전·탈퇴 유예 회원에게 "대상이 있는지"를 먼저 알려줄 필요가 없고, 계정 문제를 먼저 안내하는 편이 해결이 빠르다.
- ③과 ④를 둘 다 404로 주므로 "글은 있지만 내 것이 아님"과 "글이 없음"을 구분할 수 없다 (P-4).
- 구현: ③·④는 `author_id = :me` 조건 조회 한 번으로 함께 처리할 수 있다 (02 §5 소유 검사).
- ②의 계정 상태 검사는 대상과 무관하게 같은 결과를 주므로 대상의 존재를 드러내지 않는다. [30 좋아요](./30-like.md) §2는 ③을 인증 확인보다 먼저 적었는데, 응답이 기능마다 달라지지 않도록 이 순서로 맞춰 달라고 요청한다.

## 4. 응답 코드

| 코드 | 언제 | 이유 코드 (REST 본문 `code`) | SSR 화면 |
|---|---|---|---|
| **401** | 로그인이 필요한데 비회원 | `LOGIN_REQUIRED` | 로그인 화면으로 이동, 로그인 후 원래 페이지로 (07 §6) |
| **403** | 계정 상태 때문에 할 수 없음 | `EMAIL_NOT_VERIFIED` / `ACCOUNT_WITHDRAWN` | 이유와 해결 방법 안내 (인증 메일 다시 보내기 / 복구 화면) |
| (로그인 실패) | 정지된 계정으로 로그인 | `ACCOUNT_SUSPENDED` | "정지된 계정이에요 (~11월 1일까지). 사유: …" — 로그인 화면에서 안내 (P-7) |
| **404** | 대상이 없음, 볼 수 없음, 내 것이 아님, 관리자 전용(로그인한 일반 회원) | `NOT_FOUND` (하나로 통일, 세분화하지 않음) | 공통 "볼 수 없는 페이지예요" (06 §3-1과 같은 화면) |
| **400** | 요청 자체가 규칙에 어긋남 | `CANNOT_LIKE_OWN_POST`, `CANNOT_REPORT_OWN` 등 | 해당 위치에 안내 문구 |
| **409** | 상태 충돌 | `VERSION_CONFLICT`(04·05), `NICKNAME_CHANGE_TOO_SOON`(09) 등 기존 정의 | 기존 문서의 처리 |

> **403은 계정 상태에만 쓴다.** "남의 글이라서 안 됨"에는 403을 쓰지 않는다 (P-4).

## 5. 글

### 5-1. 보기 (글 상세)

| 글 상태 | 비회원 | 인증 전·회원 | 작성자 | 관리자 |
|---|:-:|:-:|:-:|:-:|
| 발행 · `PUBLIC` | ✅ | ✅ | ✅ | ✅ |
| 발행 · `PRIVATE` | 404 | 404 | ✅ (🔒 배지) | 404 |
| 수정 중 (`post_draft` 있음) | 마지막 발행본 | 마지막 발행본 | 마지막 발행본 + "수정 중" 안내 | 마지막 발행본 |
| 임시글 (`DRAFT`) | 404 | 404 | ✅ ("임시저장" 배지) | 404 |
| 휴지통 | 404 | 404 | **404** (휴지통 목록에서만) | 404 |
| 관리자 숨김 | 404 | 404 | ✅ + "운영 정책에 따라 숨겨진 글이에요" | ✅ (관리자 화면) |
| 작성자가 탈퇴 유예 | 404 | 404 | — (복구 화면만) | 404 |

- 탈퇴 유예 회원 본인은 P-12에 따라 복구 화면만 본다.
- 관리자 숨김의 세부(작성자에게 보이는 범위, 이의 제기)는 [43 문서](./43-report-hide.md)에서 확정한다.

### 5-2. 쓰기 행동

| 행동 | 비회원 | 인증 전 | 회원 (남의 글) | 작성자 | 관리자 (남의 글) |
|---|:-:|:-:|:-:|:-:|:-:|
| 새 글 만들기 | 401 | 403 | — | ✅ | — |
| 자동 저장·수동 저장 | 401 | 403 | 404 | ✅ | 404 |
| 발행·다시 발행 | 401 | 403 | 404 | ✅ | 404 |
| 변경 취소 (작업본 삭제) | 401 | 403 | 404 | ✅ | 404 |
| 공개 범위 변경 | 401 | 403 | 404 | ✅ | 404 |
| 삭제 (휴지통으로) | 401 | ✅ | 404 | ✅ | 404 |
| 복구 · 영구 삭제 | 401 | ✅ | 404 | ✅ (휴지통 글만, 아니면 404) | 404 |
| 숨김 · 숨김 해제 | 401 | 404 | 404 | 404 | ✅ |

- 휴지통 글에 대한 저장·발행·공개 범위 변경은 작성자라도 404 (13 §2-3).
- 인증 전 회원도 **자기 글 삭제·복구는 허용**: 지우는 것은 남에게 해를 주는 행동이 아니다.
- 정지 회원은 로그인할 수 없으므로 정지 기간에는 자기 글도 지울 수 없다 (P-7의 결과).

## 6. 댓글 (규칙 상세는 [21 댓글](./21-comment.md))

| 행동 | 비회원 | 인증 전 | 회원 (글 주인 포함) | 댓글 작성자 | 관리자 |
|---|:-:|:-:|:-:|:-:|:-:|
| 보기 | 글을 볼 수 있으면 ✅, 아니면 404 (06 §3) | 〃 | 〃 | 〃 | 〃 |
| 쓰기 · 답글 | 401 | 403 | ✅ | ✅ | ✅ |
| 수정 | 401 | 403 | 404 | ✅ (숨긴 댓글은 불가) | 404 |
| 삭제 | 401 | ✅ (본인 것) | 404 | ✅ | 404 |
| 신고 | 401 | 403 (P-6) | ✅ | 400 `CANNOT_REPORT_OWN` | ✅ |
| 숨김 · 숨김 해제 | 401 | 404 | 404 | 404 | ✅ |

- 댓글을 쓰려면 **그 글을 볼 수 있어야 한다** (볼 수 없으면 ③에서 404).
- 글 주인도 자기 글에 달린 남의 댓글을 수정·삭제할 수 없다 (P-8, 21 CM-10).
- **숨긴 댓글**은 작성자도 수정할 수 없고, 누구도 답글을 달 수 없다 (21 §9, 답글은 400 `REPLY_TARGET_UNAVAILABLE`). 삭제는 작성자가 할 수 있다.
- 삭제·숨김·탈퇴한 사람의 댓글 표시 문구는 21 §3-1과 [43](./43-report-hide.md) §4-2.

| 회원 정지 · 해제 | 401 | 404 | 404 | 404 | ✅ (자기 자신 불가) |

- 프로필 수정 주소에는 회원 ID가 없다 (11 §5). "남의 프로필 수정"이라는 경로 자체가 없으므로 표에서 `—`.
- 정지 회원은 로그인할 수 없으므로 프로필 수정·비밀번호 변경·탈퇴도 정지 기간에는 할 수 없다. 비밀번호 재설정(로그인 전 기능)은 가능하다 (정지가 풀린 뒤 로그인하려면 필요).

## 10. 내 글 관리·사진

| 행동 | 비회원 | 인증 전 | 회원 | 관리자 |
|---|:-:|:-:|:-:|:-:|
| 내 글 관리 (임시글·발행 글·휴지통 탭) | 401 | ✅ (본인 글만) | ✅ (본인 글만) | ✅ (본인 글만) |
| 사진 업로드 (presign·complete) | 401 | 403 (07) | ✅ | ✅ |
| 남이 올린 사진 연결 (프로필·글) | — | — | 400 `INVALID_PROFILE_IMAGE` 등 (11 §5) | 〃 |

- 내 글 관리는 주소에 사용자 값이 없고 로그인 정보로만 본인 글을 보여준다. 관리자도 남의 글 관리 화면은 없다.

### 10-1. 팔로우·피드 (상세는 [24 팔로우](./24-follow-feed.md))

| 행동 | 비회원 | 인증 전 | 회원 | 본인 | 관리자 |
|---|:-:|:-:|:-:|:-:|:-:|
| 팔로워·팔로잉 수·목록 보기 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 팔로우 · 언팔로우 | 401 | ✅ (인증 불필요, 24) | ✅ | 400 `CANNOT_FOLLOW_SELF` | ✅ (회원과 같음) |
| 피드 (`/feed`) | 401 | ✅ | ✅ | — | ✅ |
| 없는 블로그·탈퇴 유예 블로그 대상 | 404 | 404 | 404 | — | 404 |

- 탈퇴 유예 회원은 남의 팔로워·팔로잉 목록과 수에서 빠진다 (24 F-6). 피드는 06 R-2a 공용 조건을 쓴다.

### 10-2. 태그 (상세는 [22 태그](./22-tag.md))

| 행동 | 비회원 | 인증 전 | 회원 | 관리자 |
|---|:-:|:-:|:-:|:-:|
| 태그별 목록·전체 태그 목록 보기 | ✅ | ✅ | ✅ | ✅ |
| 자동완성 | 공개 글의 태그 | 공개 글의 태그 + 내 태그 | 〃 | 〃 |
| 태그 붙이기 | 글 발행 권한을 따른다 (§5-2) | | | |

- 태그 목록·글 수에는 공개·발행 글만 나온다 (06 R-2a, 관리자 숨김 제외 포함).

### 10-3. 알림 (상세는 [25 알림](./25-notification.md))

| 행동 | 비회원 | 인증 전 | 받은 사람 본인 | 다른 회원 | 관리자 (남의 알림) |
|---|:-:|:-:|:-:|:-:|:-:|
| 알림 목록·안 읽은 수 보기 | 401 | ✅ (본인 것) | ✅ | 404 | **404** |
| 읽음 처리 · 모두 읽음 · 삭제 | 401 | ✅ (본인 것) | ✅ | 404 | **404** |
| 알림 종류 끄기 | 401 | ✅ | ✅ | — | — |

- 관리자도 남의 알림을 볼 수 없다. 알림 주소에 회원 ID를 넣지 않고 로그인 정보로만 본인 알림을 보여준다.
- 탈퇴 유예 회원에게는 알림을 만들지 않는다 (25 §8, 44 §2).

## 11. 화면 표시 (NFR: 권한 없는 기능은 보이지 않게)

서버 판정과 별개로, 화면은 **할 수 없는 행동의 버튼을 아예 보여주지 않는다.**

| 화면 | 보이는 조건 |
|---|---|
| 글 상세 [수정] [삭제] [공개 범위] | 작성자 |
| 글 상세 [좋아요] 버튼 | 회원·관리자이고 작성자가 아님 (P-9). 그 외는 좋아요 수만 |
| 글 상세 [신고] | 회원·관리자이고 작성자가 아님 |
| 댓글 입력창 | 회원·관리자 (인증 전에는 "이메일 인증 후 댓글을 쓸 수 있어요 [인증 메일 다시 보내기]", 비회원에게는 "로그인하고 댓글 쓰기") |
| 댓글 [수정] | 댓글 작성자 |
| 댓글 [삭제] | 댓글 작성자 (P-8) |
| 숨긴 댓글의 [수정] [답글] | 보이지 않음 |
| 작성자 카드 [팔로우] | 내 글이 아닐 때 (비회원은 누르면 로그인 화면) |
| 댓글 [신고] | 회원·관리자이고 댓글 작성자가 아님 |
| [숨김] [숨김 해제] | 관리자 |

## 12. 공통 완료 기준 (C-OWN-1)

**권한 매트릭스 자동 테스트:** §5~§10-3의 모든 칸을 통합 테스트로 만든다 (행위자 × 대상 상태 × 행동). 06 §8의 공개 범위 매트릭스 테스트에 행동(쓰기) 축을 더한 것이다.

| # | 기준 |
|---|---|
| 1 | 남의 글·댓글에 대한 수정·삭제·발행·공개 범위 변경 요청은 **404**이고, 요청 전후 DB 값(내용·상태·`edit_version`·`updated_at`)이 같다 |
| 2 | 요청에 다른 사람의 작성자 ID를 넣어 보내도 무시되고 결과는 1과 같다 |
| 3 | 볼 수 없는 대상(비공개·임시·휴지통·숨김·탈퇴 유예)과 없는 대상의 응답이 같다 |
| 4 | 비회원의 쓰기 요청은 401(SSR은 로그인 화면), 인증 전·탈퇴 유예 회원은 403과 이유 코드다 |
| 4-1 | 회원을 정지하면 그 회원의 모든 세션이 즉시 끊기고, 정지 기간에는 로그인할 수 없다 |
| 5 | 관리자도 남의 글·댓글 내용을 수정·삭제할 수 없고, 남의 비공개 글을 볼 수 없다 |
| 6 | 관리자 전용 주소에 비회원이 접근하면 있는 주소·없는 주소 모두 401(로그인 화면)이고, 로그인한 일반 회원은 404다 |
| 7 | 화면에는 §11 조건을 만족할 때만 버튼이 보인다 |
| 8 | 글 주인이 자기 글에 달린 남의 댓글을 삭제하면 404이고 댓글은 그대로다 |
| 9 | 남의 알림 ID로 읽음·삭제를 요청하면 관리자도 404다 |

# 다크 모드 설계

> 작성일 2026-10-03 · 담당: 나민서 · 상태: **초안 (항목 확인 중)**
> 관련 요구사항: 다크 모드 (Tier C, 화면 요소 · ERD 무관). 연관: [10 목록](./10-post-list.md) L-7(썸네일 빈 영역 색), [11 프로필](./11-profile.md) §4-3(기본 아이콘 명도 대비), [12 본문 정화](./12-content-sanitize.md) §8(CSP)
> 목적: SSR이든 SPA든 **같은 방식·같은 색 이름**으로 다크 모드를 만들 수 있게 규격을 정한다.

## 1. 결정 사항

| # | 안건 | 결정 | 이유 |
|---|---|---|---|
| T-1 | 선택지 | **시스템 설정 / 라이트 / 다크** 3가지 | 처음엔 기기 설정을 따르고, 원하면 고정할 수 있다. "시스템"으로 되돌리는 방법도 있어야 한다 |
| T-2 | 처음 기본값 | **시스템 설정** (`prefers-color-scheme`) | 기기를 다크로 쓰는 사람에게 처음부터 다크로 보인다 |
| T-3 | 저장 위치 | **브라우저(`localStorage`)** — 기기마다 따로 | 비회원도 쓸 수 있고 서버·DB가 필요 없다. 계정에 저장해 기기 간 동기화하는 것은 개인 확장 |
| T-4 | 전환 버튼 | 헤더 맨 오른쪽, 누를 때마다 시스템 → 라이트 → 다크 순환. 아이콘(🖥/☀️/🌙) + 글자 설명(`aria-label`, 툴팁) | 어느 페이지에서나 같은 자리 |
| T-5 | 깜빡임 방지 | **`<head>`에서 작은 외부 스크립트(`/js/theme-init.js`)를 `defer` 없이 먼저 실행**해 `<html data-theme>`을 정한다 | 화면을 그리기 전에 테마가 정해져야 밝은 화면이 번쩍이지 않는다. **12 §8 CSP(`script-src 'self'`)가 인라인 스크립트를 막으므로** 인라인이 아닌 우리 서버 파일로 한다 |
| T-6 | 색 정의 | **색 토큰(CSS 변수) 하나의 목록**(§3)을 라이트·다크 값으로 정의. 화면 코드에서는 색을 직접 쓰지 않는다 | 다크 값을 한곳에서 바꾸면 모든 화면에 반영된다. 세 사람이 같은 토큰 이름을 쓴다 |
| T-7 | 명도 대비 | 본문 글자 **4.5 : 1 이상**, 큰 글자·아이콘·입력칸 테두리 **3 : 1 이상** (WCAG 2.2 AA) | 다크 모드에서 흔히 회색 글자가 안 읽히는 문제를 막는다 |
| T-8 | 로그아웃 | 테마 설정은 **지우지 않는다** | 개인 정보가 아니다 (07 §7은 임시 글 데이터만 지움) |

## 2. 동작

```
<head>
  <script src="/js/theme-init.js"></script>        ← 동기 실행 (작은 파일, 1KB 미만)
  <link rel="stylesheet" href="/css/app.css">
</head>

theme-init.js
  saved = localStorage.getItem('theme')            // 'system' | 'light' | 'dark' | 없음
  mode  = saved in ('light','dark') ? saved : (matchMedia('(prefers-color-scheme: dark)') ? 'dark' : 'light')
  document.documentElement.dataset.theme = mode    // <html data-theme="dark">
  document.documentElement.dataset.themeChoice = saved || 'system'
  (localStorage 접근이 막힌 환경이면 try/catch로 시스템 설정만 따른다)
```

| 상황 | 동작 |
|---|---|
| 처음 방문 | 시스템 설정을 따른다 |
| 버튼을 누름 | 시스템 → 라이트 → 다크 → 시스템 … `localStorage`에 저장하고 즉시 `data-theme` 변경 |
| "시스템"을 고른 상태에서 기기 설정이 바뀜 | 페이지를 새로 고치지 않아도 따라 바뀐다 (`matchMedia` 변경 감지) |
| 라이트·다크로 고정한 상태 | 기기 설정이 바뀌어도 그대로 |
| JS가 꺼져 있음 | CSS의 `@media (prefers-color-scheme: dark)`만으로 시스템 설정을 따른다 (버튼은 숨김) |

- 테마가 바뀔 때 색이 서서히 바뀌는 애니메이션은 넣지 않는다 (처음 그릴 때 번쩍임의 원인이 되고, `prefers-reduced-motion` 사용자에게 불편하다).

## 3. 색 토큰

화면 코드는 아래 **토큰 이름만** 쓴다. 값은 공통 기본값이며, 개인 서비스는 **값만** 바꿔도 된다 (이름은 바꾸지 않는다).

| 토큰 | 쓰는 곳 | 라이트 | 다크 |
|---|---|---|---|
| `--color-bg` | 페이지 배경 | `#FFFFFF` | `#121212` |
| `--color-surface` | 카드·헤더·상자 | `#FFFFFF` | `#1E1E1E` |
| `--color-text` | 본문 글자 | `#212529` | `#E9ECEF` |
| `--color-text-muted` | 날짜·보조 글자 | `#6C757D` | `#ADB5BD` |
| `--color-border` | 구분선·카드 테두리 | `#DEE2E6` | `#343A40` |
| `--color-brand` | 링크·강조 글자 | 각자 | 각자 (다크에서는 더 밝게) |
| `--color-brand-fill` | 흰 글자가 올라가는 버튼 배경 | 각자 | 각자 |
| `--color-danger` | 삭제·오류 | `#C92A2A` | `#FF6B6B` |
| `--thumb-empty` | 썸네일 없는 카드의 빈 영역 | `#F1F3F5` | `#2B2F33` (10 L-7) |
| `--color-code-bg` | 코드 블록 배경 | `#F8F9FA` | `#1A1B1E` |
| `--color-focus` | 키보드 포커스 테두리 | `#1C7ED6` | `#74C0FC` |

```css
:root, [data-theme="light"] { --color-bg: #FFFFFF; … }
[data-theme="dark"]         { --color-bg: #121212; … }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --color-bg: #121212; … }   /* JS 없을 때 */
}
```

- 다크 배경은 순수 검정(`#000`) 대신 `#121212`를 쓴다. 순수 검정 위의 흰 글자는 눈이 부시고 번진다.
- 위 값은 모두 T-7 대비 기준을 만족해야 한다. 각자 `--color-brand`를 정할 때 배경 대비 4.5 : 1(글자) / `brand-fill` 위 흰 글자 4.5 : 1을 확인한다.

## 4. 요소별 규칙

| 요소 | 다크 모드에서 |
|---|---|
| 본문 이미지·썸네일·프로필 사진 | **그대로** (색을 뒤집거나 어둡게 하지 않는다) |
| 기본 프로필 아이콘 | 11 §4-3의 8가지 배경색이 다크에서도 글자와 4.5 : 1 이상 (이미 결정) |
| 코드 강조 (highlight.js) | 테마 파일 두 개(`github.css` / `github-dark.css`)를 `data-theme`에 맞춰 적용 |
| 본문 표·인용·체크리스트 | 토큰 색만 사용 (`--color-border`, `--color-text-muted`) |
| 에디터 | 쓰는 에디터가 다크 테마를 지원하면 같은 `data-theme`로 켠다 (각자). 지원하지 않으면 에디터만 라이트로 두되 주변은 다크 |
| 입력칸·버튼 | 테두리 대비 3 : 1 이상 |
| 상태 배지 (🌐/🔒/수정 중 등) | 색만으로 구분하지 않고 글자·아이콘을 함께 (04 §2-2와 같은 원칙) |
| 링크 미리보기(OG)·메일 | 테마와 무관 (라이트 기준) |
| `<meta name="color-scheme" content="light dark">` | 넣는다 — 스크롤바·기본 입력칸 등 브라우저 요소도 테마를 따른다 |

## 5. 공통 완료 기준

| # | 기준 |
|---|---|
| 1 | 처음 방문하면 기기 설정(라이트/다크)을 따른다 |
| 2 | 버튼으로 시스템·라이트·다크를 고를 수 있고, 새로 고침·다른 페이지로 이동해도 유지된다 |
| 3 | 다크 모드로 설정한 상태에서 페이지를 열 때 밝은 화면이 잠깐 보이지 않는다 |
| 4 | 인라인 스크립트 없이 동작한다 (CSP `script-src 'self'` 위반 없음) |
| 5 | "시스템"을 고른 상태에서 기기 설정을 바꾸면 새로 고치지 않아도 따라 바뀐다 |
| 6 | 라이트·다크 모두 본문 글자 대비 4.5 : 1, 테두리·아이콘 3 : 1 이상이다 (자동 검사 도구로 주요 화면 확인) |
| 7 | 썸네일 빈 영역이 라이트 `#F1F3F5`, 다크 `#2B2F33`이다 (10 L-7) |
| 8 | JS가 꺼져 있어도 기기 설정에 맞는 테마로 보인다 |

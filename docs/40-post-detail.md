# 글 상세 설계

> 작성일 2026-10-03 · 담당: 나민서 · 상태: **초안 (항목 확인 중)**
> 관련 요구사항: C-READ-2(글 상세). 연관: [02 아키텍처](./02-architecture.md) §4-2, [05 발행](./05-publish.md), [06 공개 범위](./06-visibility.md), [09 닉네임](./09-nickname.md) §9, [10 목록](./10-post-list.md), [12 본문 정화](./12-content-sanitize.md), [13 삭제·탈퇴](./13-delete-withdraw.md), [42 권한](./42-permission-matrix.md)
> 이미 결정된 것: 404 판정(06), 렌더링(12), 수정됨 표시(05). 이 문서는 **화면 구성, 주소, 작성자가 볼 때, 다른 기능(댓글·태그·좋아요·조회수·팔로우·사진)이 상세 화면에 붙는 자리, 링크 미리보기**를 정한다.
> 2026-10-06 수정: 강성찬(21~25)·김민서(30~34) 문서와 맞춤. 조회 기록은 김민서 31 방식으로 바꾸고, 댓글 영역·태그·GIF·팔로우 버튼을 반영했다.

## 1. 결정 사항

| # | 안건 | 결정 | 이유 |
|---|---|---|---|
| R-1 | 주소 | `/@{handle}/posts/{id}` — 기존 결정 (01 Q4, 05 §8) | |
| R-2 | 볼 수 있는지 판정 | `PostAccessPolicy.canRead` 하나로 — 기존 결정 (02 §4-2, 06 R-1). 판정 순서는 42 §3 | |
| R-3 | 주소의 블로그와 글의 작성자가 다를 때 | **볼 수 있는 글이면 올바른 주소로 301, 볼 수 없으면 404** | 링크를 잘못 옮겨 적어도 글에 닿는다. 판정을 먼저 하므로 남의 비공개 글의 존재·작성자는 드러나지 않는다 |
| R-4 | 작성자가 자기 **임시글** 주소를 열 때 | **에디터로 이동** (`302 → /write/{id}`) | 임시글은 아직 렌더링하지 않는다 (04 §2-4). 작성자가 원하는 것은 "이어 쓰기"다 |
| R-5 | 작성자가 **수정 중인 글**을 열 때 | **독자와 같은 마지막 발행본 + 상단 안내** "수정 중인 내용이 있어요 [이어서 수정] [변경 취소]" | 독자가 지금 보는 모습을 작성자도 확인할 수 있다. 작업본 미리보기는 에디터에서 한다 |
| R-6 | 표시 날짜 | **공개 글은 `first_public_at`** (목록 카드와 같은 날짜), 비공개 글은 `published_at` (작성자만 봄). 다시 발행했으면 옆에 "수정됨 · 10월 3일"(`edited_at`) | 목록에서 본 날짜와 상세 날짜가 다르면 혼란스럽다 (10 L-1) |
| R-7 | 조회 기록 시점 | **김민서 [31 조회수](./31-view-count.md) W-4를 따른다**: 글이 화면에 보이는 상태로 1초가 지나면 브라우저가 `POST /api/posts/{id}/views`를 보낸다. **상세 조회 자체는 조회수를 세지 않는다** | 조회수 담당 문서의 결정. 봇·미리 불러오기·백그라운드 탭이 자연히 빠진다. 기록 실패가 상세 응답에 영향을 주지 않는다 (01 원칙 5) |
| R-8 | 조회 기록 제외 | 31 W-3을 따른다 (작성자 본인, 봇·링크 미리보기, 미리 불러오기, 볼 수 없는 글). **관리자 제외는 31에 추가를 요청** (신고 처리로 연 조회가 섞이지 않게) | 제외 판정은 기록 API(31) 한곳에서 한다 |
| R-9 | 캐시 | 모든 상세 응답 `Cache-Control: private, no-cache` | 좋아요 여부·작성자 버튼처럼 **보는 사람마다 다른 내용**이 들어 있어 공유 캐시(CDN)에 넣으면 안 된다. `PUBLIC`이 아닌 글은 06 R-5대로 `no-store` |
| R-10 | 볼 수 없는 글의 화면 | 06 §3-1의 공통 404 화면·미리보기 문구 그대로 | 없는 글과 같아야 한다 |

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ [임시저장] [🔒 비공개] [수정 중]          ← 작성자에게만, 해당될 때      │
│ JPA N+1 문제를 fetch join으로 해결하기       ← 제목 (h1)                  │
│ (사진) 김민서 @kim755030 · 2026.10.02 · 수정됨 10월 3일                 │
│                                [수정] [공개 범위 ▾] [삭제]  ← 작성자만  │
├──────────────────────────────────────────────────────────┤
│ 본문 (content_html)                                         │
│   h2~h6, 표, 코드(highlight.js), 체크리스트, 이미지(lazy) …      │
├──────────────────────────────────────────────────────────┤
│ #spring #jpa                              ← 태그 (22 §9)                 │
│ ♥ 12   [좋아요]   조회 1,234   [신고]      ← 42 §11 조건으로 표시        │
├──────────────────────────────────────────────────────────┤
│ (사진) 김민서 @kim755030          [팔로우]  ← 작성자 카드 (24 §2-1)       │
│ 백엔드 개발을 공부하고 있어요.  [블로그 가기]                                │
├──────────────────────────────────────────────────────────┤
│ 댓글 3                                    ← 첫 20개 포함 (21 CM-3)       │
│ …                                                                         │
│ [댓글 더 보기]                                                            │
└──────────────────────────────────────────────────────────┘
```

| 요소 | 데이터 | 규칙 |
|---|---|---|
| 상태 배지 | `status`, `visibility`, `post_draft` 유무 | **작성자에게만.** 독자에게는 보일 일이 없다(볼 수 있는 글은 모두 공개·발행 글) |
| 제목 | `post.title` | 페이지의 유일한 `h1`. 본문 제목은 `h2`부터 (12 S-9). HTML 이스케이프 |
| 작성자 영역 | `member.profile_image_url`, `nickname`, `handle` | **`닉네임 @블로그주소`** (09 N-9), 누르면 `/@handle`. 사진이 없으면 기본 아이콘 (11 §4-3) |
| 날짜 | R-6 | `<time datetime="ISO">`. 24시간 이내는 "N시간 전" (10 L-5와 같은 형식) |
| 수정됨 | `post.edited_at` | 값이 있을 때만 "수정됨 10월 3일". 공개 범위만 바꾼 경우는 표시되지 않는다 (06 V-6) |
| 작성자 버튼 | — | [수정](→ 에디터) [공개 범위 ▾](PUBLIC/PRIVATE 즉시 변경, 06 §4) [삭제](→ 휴지통 확인창, 13 §2-2). 42 §11 |
| 본문 | `post.content_html` | 저장된 값을 그대로 출력 (조회 때 렌더링하지 않음, 12). 코드 블록이 있을 때만 highlight.js를 불러온다 |
| 태그 | `post_tag` → `tag.name` | **`position` 순서**로 `#이름`, 링크는 `/tags/{인코딩된 이름}` ([22 태그](./22-tag.md) §9) |
| 좋아요 | `post.like_count`, 내가 눌렀는지 | 태그 아래 반응 줄의 맨 앞. 버튼은 회원·관리자이고 작성자가 아닐 때만 (42 P-9). 그 외는 수만. "내가 눌렀는지"는 상세 조회 때 함께 가져온다 (§6, [30 좋아요](./30-like.md)) |
| 조회수 | `post.view_count` | 좋아요 옆에 "조회 1,234" (1만 이상 `1.2만`). 안내 문구 위치도 같은 줄 ([31](./31-view-count.md) W-8). 목록 카드에는 없음 (10 §2) |
| 신고 | — | 회원·관리자이고 작성자가 아닐 때만 ([43 문서](./43-report-hide.md)) |
| 작성자 카드 | `member.bio` | 소개는 글자만, 줄바꿈 유지 (11 §3) |
| 팔로우 버튼 | 내가 팔로우 중인지 | 작성자 카드 오른쪽. 상태별 표시는 [24 팔로우](./24-follow-feed.md) §2-1 (비회원 [팔로우] → 로그인, 팔로우 중 [팔로잉 ✓], **내 글이면 버튼 없음**) |
| 댓글 | `post.comment_count`, 첫 20개 | **최상위 첫 20개(+ 각 답글 처음 3개)를 상세 HTML에 포함(SSR)**, 머리말에 `comment_count`. 세부 규칙은 [21 댓글](./21-comment.md) CM-3·§6 |
| 댓글 바로 가기 | `?comment={id}` | 알림 링크 `/@주소/posts/{글}?comment={id}#comment-{id}`로 들어오면 `comment` 값을 댓글 영역에 넘겨 21 §6 `around`로 그 댓글부터 그린다 (SSR·SPA 같음, [25 알림](./25-notification.md)) |
| GIF | 본문 안 GIF | 첫 장면 + ▶, 누르면 재생. 상세 페이지에 `/js/gif-play.js`와 ▶ CSS를 넣는다 ([23 사진](./23-image.md) §5) |
| 개인 확장 자리 | — | 제목 위 카테고리 경로, 본문 아래 관련 글·이전/다음 글, 오른쪽 사이드바 (나민서 개인 확장) |

### 2-1. 작성자가 볼 때의 상태별 화면

| 상태 | 화면 |
|---|---|
| 발행 · `PUBLIC` | 독자와 같음 + 작성자 버튼 |
| 발행 · `PRIVATE` | 독자와 같은 모습 + 🔒 배지 + "나만 볼 수 있는 글이에요" |
| 수정 중 | **마지막 발행본** + 상단 안내 "수정 중인 내용이 있어요(10월 3일 14:03 저장) [이어서 수정] [변경 취소]" (R-5) |
| 임시글 | 에디터로 이동 (R-4) |
| 관리자 숨김 | 상단 안내 "운영 정책에 따라 숨겨진 글이에요. 다른 사람에게는 보이지 않아요" (42, 세부는 43) |
| 휴지통 | 404 (휴지통 목록에서만, 13) |

## 3. 주소 처리

```
GET /@{handle}/posts/{id}
 ① handle에 대문자가 있으면 소문자 주소로 301 (08 §6)
 ② id가 숫자가 아니면 404
 ③ 글 조회 (작성자 JOIN) → canRead (42 §3) → 볼 수 없으면 404
 ④ handle ≠ 글 작성자의 handle → 301 /@{올바른 handle}/posts/{id} (R-3)
 ⑤ 임시글이고 작성자 본인 → 302 /write/{id} (R-4)
 ⑥ 200 상세
```

- ③ 다음에 ④를 하는 이유: 볼 수 없는 글에 301을 주면 "이 번호의 글은 다른 사람이 썼다"는 사실이 드러난다.
- 쿼리 문자열(`?utm_source=…`, `?comment=…`)은 정규 주소에 넣지 않는다. 정규 주소는 `<link rel="canonical">`로 알린다. `?comment`만 댓글 영역에 넘긴다 (§2).

## 4. 조회 기록 (김민서 [31 조회수](./31-view-count.md)를 따른다)

```
GET 상세 200 응답            ← 여기서는 조회수를 세지 않는다
 → 브라우저: 화면에 보이는 상태로 1초 지나면 POST /api/posts/{id}/views (한 번만, 31 §4-1)
 → 31의 기록 API가 제외 판정·중복 판정 후 Redis에 모아 DB에 반영 (항상 204)
```

| 항목 | 규칙 |
|---|---|
| 이 문서가 정하는 것 | 31 §4-1 스크립트를 상세 페이지에 넣는 것뿐 (`/js/post-view.js`, `<script src defer>`. CSP `script-src 'self'`를 지키기 위해 인라인으로 넣지 않는다. 글 ID·CSRF 토큰은 `data-` 속성으로 넘긴다) |
| 넣는 페이지 | 독자가 보는 공개·발행 글 상세. **작성자 본인에게는 넣지 않는다** (서버도 31 W-3대로 한 번 더 제외) |
| 제외·중복 판정 | 31 W-1·W-3 (작성자·봇·미리 불러오기·볼 수 없는 글). 관리자 제외는 31에 추가 요청 |
| JS가 꺼진 독자 | 세지 않는다 (31 W-4의 결과) |
| 화면의 조회수 | 저장된 `view_count`를 그대로 표시 (이번 방문의 +1을 기다리지 않음) |

## 5. 링크 미리보기·검색 엔진 (공개 글)

```html
<title>{제목} - {닉네임}</title>
<meta name="description" content="{excerpt 앞 160자}">
<link rel="canonical" href="https://{도메인}/@{handle}/posts/{id}">
<meta property="og:type" content="article">
<meta property="og:title" content="{제목}">
<meta property="og:description" content="{excerpt 앞 160자}">
<meta property="og:image" content="{첫 이미지의 원본 주소, 없으면 서비스 기본 이미지}">
<meta property="article:published_time" content="{first_public_at}">
<meta property="article:modified_time" content="{edited_at}">   <!-- 있을 때만 -->
```

| 항목 | 규칙 |
|---|---|
| `og:image` | 글 상세·미리보기는 **원본** 이미지 (10 §6) |
| 비공개·임시·볼 수 없는 글 | 06 §3-1의 공통 문구 + `noindex` (작성자 본인이 보는 비공개 글도 `noindex`) |
| 값 이스케이프 | 제목·요약은 HTML 속성 이스케이프 |

## 6. 성능

| 항목 | 기준 |
|---|---|
| 쿼리 수 | 글+작성자 1, 태그 1, 내가 좋아요 눌렀는지 1, 내가 팔로우 중인지 1, (작성자일 때) 작업본 유무 1 → **최대 5번** + 댓글 첫 20개(21 §6) |
| 조회 컬럼 | `content_md`는 읽지 않는다 (`content_html`만) |
| 응답 시간 | 300ms 이내 (02 §6) |
| 조회 기록 | 상세 응답 경로에서 하지 않는다 (§4, 브라우저가 별도 요청) |

## 7. 공통 완료 기준 (C-READ-2)

**권한 판정은 [42 문서](./42-permission-matrix.md) §5-1 표를 통합 테스트로 확인한다.** 아래는 이 문서가 더하는 기준이다.

| # | 기준 |
|---|---|
| 1 | 없는 글, 남의 비공개·임시 글, 휴지통 글, 숨긴 글(남이 볼 때), 탈퇴 유예 작성자의 글은 **404**이고, 상태 코드·본문·미리보기 문구가 모두 같다 |
| 2 | 볼 수 있는 글을 다른 블로그 주소로 열면 올바른 주소로 301, 볼 수 없는 글은 같은 상황에서 404다 |
| 3 | 작성자가 수정 중인 글을 열면 독자와 같은 마지막 발행본과 "수정 중" 안내가 보인다 |
| 4 | 다시 발행한 글에만 "수정됨"이 보이고, 공개 범위만 바꾼 글에는 보이지 않는다 |
| 5 | 작성자 영역에 `닉네임 @블로그주소`가 보인다 |
| 6 | [수정]·[삭제]·[공개 범위]는 작성자에게만, [좋아요]·[신고]는 작성자가 아닌 회원에게만 보인다 |
| 7 | 상세 GET만으로는 조회수가 바뀌지 않고, 작성자 본인이 보는 상세에는 조회 기록 스크립트가 없다 (기록·제외 기준은 31 완료 기준) |
| 8 | 인라인 스크립트 없이 동작한다 (조회 기록·GIF 재생 모두 외부 파일) |
| 9 | 응답에 `Cache-Control: private`가 있고, `PUBLIC`이 아닌 글은 `no-store`다 |
| 10 | 공개 글에는 `canonical`·OG 태그가 있고, 그 밖의 경우는 공통 문구와 `noindex`다 |
| 11 | 댓글 첫 20개가 상세 HTML에 들어 있고, `?comment={id}`로 열면 그 댓글이 보이며 `canonical`에는 `?comment`가 없다 |
| 12 | 태그가 입력한 순서대로 `/tags/{인코딩된 이름}` 링크로 보인다 |
| 13 | 내 글에는 [팔로우]·[좋아요]·[신고] 버튼이 없다 |
